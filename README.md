# gradia-dashboard
Claude projekti. Tässä dashboardissa haen opetushallituksen sivustolta olennaisia tietoja Jyväskylän Gradia opiston kannalta. Haku tapahtuu Vipunen API palvelun kautta. Dashboard oli osa aiempaa rekrytointiprosessiani, jossa tehtävänä oli yksinkertaistetusti tuottaa hyödyllistä tietoa Vipunen API:sta tekoälyn avulla.
